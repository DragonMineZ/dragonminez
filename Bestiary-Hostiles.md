# Bestiary — Hostiles

Hostile mobs that will attack players on sight. The Red Ribbon Army mobs spawn in the **Overworld (Earth)** — DMZ has no separate "Earth" dimension, it reuses the vanilla Overworld and targets specific vanilla biomes/structures — while the Frieza Soldiers spawn on **Planet Namek**.

> Drops below come from each mob's loot table (`data/dragonminez/loot_tables/entities/`). "Looting" means the count is boosted by the Looting enchantment (+0–1 per level).

## Bandit

| | |
| :-- | :-- |
| Entity id | `dragonminez:bandit` |
| Dimension | Overworld (Earth) |
| Where it spawns | Savanna, forest and jungle biomes, plus near savanna/plains villages and woodland mansions |
| Spawn group | 1–3 (spawn weight 5) |

**Drops:**

- **1–2 Raw Beef** (+0–1 Looting) — drops **cooked** (Steak) if the bandit dies while on fire.

## Red Ribbon Soldier

| | |
| :-- | :-- |
| Entity id | `dragonminez:red_ribbon_soldier` |
| Dimension | Overworld (Earth) |
| Where it spawns | Near savanna, plains and snowy villages |
| Spawn group | 3–6 (spawn weight 20) |

**Drops:**

- **1–3 Redstone** (+0–1 Looting)
- **1–3 Iron Nugget** (+0–1 Looting)

## Red Ribbon Robots

Three robot variants share the same drops and spawn conditions; they differ in model/size and spawn rate.

| | |
| :-- | :-- |
| Entity ids | `dragonminez:robot1`, `dragonminez:robot2`, `dragonminez:robot3` |
| Dimension | Overworld (Earth) |
| Where they spawn | Near savanna, plains and snowy villages |
| Spawn group | 1–2 each (weights: robot1 = 5, robot2 = 16, robot3 = 15) |

**Drops (each variant):**

- **1–2 Iron Ingot** (+0–1 Looting)
- **1–2 Redstone** (+0–1 Looting)

## Frieza Soldiers

Frieza's army invades **Planet Namek**. Three variants share identical drops and spawn conditions, differing only in model.

| | |
| :-- | :-- |
| Entity ids | `dragonminez:saga_friezasoldier01`, `...02`, `...03` |
| Dimension | Planet Namek |
| Where they spawn | Ajissa Plains and Sacred Land biomes (Namek) |
| Spawn group | 1 each (spawn weight 2) |

**Drops (each variant):**

- **1–2 Iron Ingot** (+0–1 Looting)
- **Blaster Cannon** — rare (~5% chance, slightly increased by Looting)
