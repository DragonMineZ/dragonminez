# Controls

DMZ's default key bindings and key combinations. Everything here is **rebindable** in Minecraft's *Options → Controls*.

> **Left Alt** is the **Second Function** key — held on its own it makes you **power down (descend)**, and it's also the modifier for the combinations further down.

## Menus

| Key | Action |
| :-- | :-- |
| **V** | Open the **Character Menu** (stats, party, skills, sagas, minigames, config — see [[Menu|Menu]]). |
| **X** | Open the **Combat Radial** (transform, skills, actions). |
| **H** | **Instant Transmission** menu / **Space Pod** menu (context-dependent). |

## Combat & actions

| Key | Action |
| :-- | :-- |
| **C** | **Charge Ki** (hold to build energy and power release). |
| **G** | **Action** key — charge the selected action (transform, etc.). |
| **Left Alt** | **Descend** — power down your current form. |
| **R** | **Dash** (and double-dash). |
| **Z** | **Lock-on** to a target. |
| **Right Mouse** | **Block** (with a weapon). |

## Movement & sensing

| Key | Action |
| :-- | :-- |
| **F** | Toggle **Flight** on/off. |
| **F4** | **Ki Sense** — detect nearby entities and their power levels. |

## Techniques

Save techniques to slots and fire them with a modifier + number:

| Keys | Action |
| :-- | :-- |
| **Alt + 1 / 2 / 3 / 4** | Fire technique slots **1–4**. |
| **Ctrl + 1 / 2 / 3 / 4** | Fire technique slots **5–8**. |

## Key combinations

| Combination | Action |
| :-- | :-- |
| **Alt + F** | **Switch flight mode** between **Combat** and **Exploration** flight (see [[Skills & Abilities|Abilities]]). |
| **Alt (hold)** | **Descend** — power down a transformation. |
| **Alt + G** | Drop one transformation/stack tier while descending. |
| **Alt + number** / **Ctrl + number** | Fire your saved [[Techniques|Techniques]]. |

## Minigames

| Keys | Action |
| :-- | :-- |
| **Arrow keys** (← ↓ ↑ →) | Rhythm training minigame inputs (see [[Menu|Menu]]). |
