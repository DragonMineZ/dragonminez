# This is the DragonMineZ Developer Wiki

This wiki is for developers who want to help with DMZ modding, or configuring their DMZ files.

If you are looking for player guides, use the main project docs instead on [Trello](https://trello.com/b/xewaqYee/dragonmine-z-trello). (Duly note that the Trello has been outdated for months, and it should not be used in reference for information related to v2.0 or later versions. We are working on a new, updated, more thorough wiki.)
