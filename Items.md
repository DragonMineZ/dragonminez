# Items

Reference for DMZ's special items and what they do.

## Dragon Ball tools

| Item | Function |
| :-- | :-- |
| **Dragon Radar** | Locates the **Earth** Dragon Balls in the Overworld. Crafted from a T1 Radar Chip + T1 Radar CPU. |
| **Namek Dragon Radar** | Locates the **Namek** Dragon Balls on Planet Namek. Crafted from a T2 Radar Chip + T2 Radar CPU. |
| **Bi-Dimensional Radar** | Works in **both** worlds — a quest reward, fused from an Earth + Namek radar (not craftable). |
| **Radar Chips / CPUs (T1, T2)** | Crafting components for the radars above. |

See [[Dragons & Wishes|Dragons-and-Wishes]] for summoning.

## Transport

| Item | Function |
| :-- | :-- |
| **Flying Nimbus** | A fast rideable cloud. **Only the pure of heart can ride it** — if your alignment isn't good enough it won't carry you. |
| **Black Nimbus** | The darker counterpart to the Flying Nimbus. |
| **Space Pod** | A one-person spacecraft used to travel between planets/dimensions (Earth ↔ Namek ↔ Sacred Planet). See [[Space Pod Destinations|Space-Pod-Destinations]]. |
| **Saiyan Ship** | A Saiyan spacecraft (also a Shenron wish). |

## Scouters & stealth

| Item | Function |
| :-- | :-- |
| **Scouters** (Red, Blue, Green, Purple) | Head-worn devices that read the **Battle Power** of entities you look at. |
| **Anti-Ki Cloak** | A curio that **hides your Battle Power** from enemy scouters, keeping your true power secret. |

## Consumables

| Item | Function |
| :-- | :-- |
| **Senzu Bean** | Fully restores health (and more) — the classic emergency heal. |
| **Might Tree Fruit** | A powerful buff fruit (applies the `mightfruit` effect — see [[Effects|Effects]]). |

## Fusion

| Item | Function |
| :-- | :-- |
| **Potara Earrings** (Yellow / Green — left & right) | Wear a matching left + right pair to **fuse** with another player. Both are Porunga wishes. |

## Stat capsules

Capsules are consumables that **permanently raise one of your attributes** when used — the **colour decides which stat** (see [[Stats & Attributes|Stats-and-Attributes]]). A normal capsule grants **+5** to its stat.

| Capsule | Stat it raises |
| :-- | :-- |
| **Red** | Strength (STR) |
| **Purple** | Strike Power (SKP) |
| **Yellow** | Resistance (RES) |
| **Green** | Vitality (VIT) |
| **Orange** | Ki Power (PWR) |
| **Blue** | Energy (ENE) |

**Gete Capsules** are the rare Gete-tech versions of each colour — same stat, but they grant **×3** the points (+15). You must have a created character to use them.
